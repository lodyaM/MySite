Windows Tweaker

Это небольшая по размерам, но очень мощная по возможностям программа, позволяющая сделать полную оптимизацию Windows всего в несколько кликов.

MSI Afterburner

MSI Afterburner – самая популярная утилита для настройки видеокарт Предоставляет удобный доступ ко всем настройкам графической подсистемы компьютера

CCleaner

CCleaner — это передовое средство для оптимизации производительности, ускорения работы ПК и безопасной работы в Интернете

Инструменты

Regedit

Regedit

Встроенный инструмент Windows для просмотра и редактирования реестра, позволяющий настраивать системные параметры и управлять конфигурацией ОС

Registrar Registry Manager

Многофункциональная утилита для работы с реестром Windows, позволяющая безопасно редактировать, восстанавливать и оптимизировать системные настройки

Registry Workshop

Компактная, но мощная утилита для работы с реестром Windows, предлагающая расширенные возможности редактирования, поиска и сравнения, недоступные в стандартном редакторе.
